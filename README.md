# school-helper

Telegram-бот и Mini App для родительского комитета класса: сборы денег, голосования,
расписание, объявления и хроника событий.

Принцип: **Telegram — поговорить, school-helper — зафиксировать.**
Обычный родитель приложение не открывает — всё, что от него нужно, делается кнопкой
под сообщением бота.

Полная спецификация: [docs/SPEC.md](docs/SPEC.md).

---

## Что уже работает (этап 1)

- подключение родителей: `/setup` в группе → ссылка-приглашение → анкета в личке;
- роли с историей выдачи: казначей, председатель, ревизор, учитель;
- сборы: создание, объявление в группу, личные сообщения каждому;
- платежи: «Я оплатил» → скрин чека → подтверждение казначея → строка в журнале;
- касса: остаток, обороты, прогресс сборов (`/касса`, `/мои`, `/очередь`);
- очередь уведомлений с ретраями и учётом заблокировавших бота;
- API Mini App с проверкой `initData` и заглушка интерфейса.

Что специально сделано именно так:

- в группу уходят только сумма и полоса прогресса — **без имён и без «17 из 24»**;
- поимённый разрез сбора доступен только казначею, председателю и ревизору;
- **учителю денежный раздел не показывается вообще**;
- деньги попадают в журнал только при подтверждении казначея;
- журнал неизменяем: правка = сторно.

## Запуск

```bash
python -m venv .venv
.venv/Scripts/pip install -e ".[dev]"

cp .env.example .env    # заполнить BOT_TOKEN, BOT_USERNAME, APP_SECRET
.venv/Scripts/python -m schoolhelper.runner
```

`APP_SECRET` генерируется так:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

### Первый запуск

1. Создать бота у [@BotFather](https://t.me/BotFather), выключить ему Privacy Mode
   (иначе он не увидит команды в группе).
2. Прописать свой Telegram id в `BOOTSTRAP_CHAIR_TG_ID` — первому `/start`
   выдадутся роли председателя и админа.
3. Добавить бота в группу класса администратором (нужно право закреплять сообщения).
4. В группе: `/setup` → появится кнопка-приглашение для родителей.
5. В личке боту: `/роли` — назначить казначея, `/реквизиты` — задать карту для переводов.

### Прод

```bash
docker compose up -d --build
```

Вебхук ставится сам, если заданы `PUBLIC_URL` и `WEBHOOK_SECRET`.
Впереди — Caddy: один домен отдаёт и API, и статику Mini App, поэтому CORS не нужен.

## Тесты

```bash
.venv/Scripts/python -m pytest -q
.venv/Scripts/python -m ruff check src tests
```

Тесты закрывают то, что дороже всего сломать: денежные инварианты, сторно,
проверку `initData` и разграничение доступа к поимённым спискам.

## Структура

```
docs/SPEC.md                  спецификация: решения и почему именно так
src/schoolhelper/
  config.py                   настройки из .env
  runner.py                   dev-режим (long polling)
  app.py                      прод: FastAPI + вебхук + статика Mini App
  core/       security.py     initData, подписанные ссылки, voter_hash
              roles.py        роли и матрица прав
              util.py         время, деньги, русские форматы
  storage/    schema.sql      полная схема БД (25 таблиц)
              money.py        журнал, остаток, прогресс сборов
              journal.py      хроника событий и аудит-лог
  services/                   бизнес-логика; ею пользуются и бот, и API
  bot/                        роутеры aiogram, очередь уведомлений
  api/                        REST для Mini App
web/index.html                заглушка Mini App
```

## Известные ограничения

- FSM-состояния живут в памяти: при рестарте незаконченный диалог
  (например, «пришлите чек») теряется. Для этапа 1 это допустимо.
- Файлы хранятся в Telegram по `file_id` — при смене токена бота ссылки на чеки
  перестанут открываться. Раз в год нужна выгрузка архива.
- Telegram-платежей нет и не планируется: провайдеры требуют мерчант-аккаунт
  юрлица. Схема «реквизиты + скрин + подтверждение» — постоянная.
